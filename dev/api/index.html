Minimap2.Minimap2 — Module
Minimap2

Native Julia port of minimap2 2.30 for single-segment, unspliced long-read mapping. It gives the same seeds, chains, mapping qualities, coordinates and CIGARs as minimap2. Main entry points: preset, MinimapIndex, map_query and paf_line.

Minimap2.update_options! — Function
update_options!(options::MapOptions, index::MinimapIndex) -> options

Complete the mapping options from the index, as minimap2's mm_mapopt_update: derive the high-occurrence threshold mid_occ from mid_occ_frac (clamped to min_mid_occ/max_mid_occ) when it is not set, raise bw_long to at least bw, and set F_SPLICE when a splice strand flag is set. The minimap2 command line calls it after loading the index; call it before map_query to reproduce it.

source

Mapping flags are the MapOptions.flag bits of minimap2 (MM_F_* in minimap.h), available as unexported constants such as Minimap2.F_CIGAR (base-level alignment) and Minimap2.F_OUT_CG (cg:Z tag).

Minimap2.sketch! — Function
sketch!(minimizers, sequence, w, k, rid, hpc) -> minimizers

Append the symmetric (w,k)-minimizers of sequence to minimizers (minimap2 mm_sketch). Each entry has x = hash << 8 | span and y = rid << 32 | last_position << 1 | strand, with 0-based positions. With hpc, k-mers are taken on the homopolymer-compressed sequence.

source
Minimap2.MinimapIndex — Type
MinimapIndex(sequences; names=nothing, k=15, w=10, hpc=false, bucket_bits=14, threads=Threads.nthreads())
MinimapIndex(sequences, options::IndexOptions; names=nothing, threads=Threads.nthreads())

Minimizer index of the reference sequences (byte vectors or strings), as built by minimap2's mm_idx_str. Reference sequences are stored as 2-bit codes with 4 for ambiguous bases.

Minimizers are stored sorted by hash in flat arrays: the positions of the i-th distinct hash keys[i] are positions[starts[i]+1:starts[i+1]], in increasing order, and directory maps the high bits of a hash to its range of keys. threads tasks sketch and sort the references; the index does not depend on it.

source
Minimap2.max_occurrence — Function
max_occurrence(index, fraction::Real) -> Int

Occurrence threshold above which the top fraction of distinct minimizers lie (minimap2 mm_idx_cal_max_occ). fraction is converted to Float32 first, like minimap2's float option -f, so 0.01 and 0.01f0 give the same threshold. A fraction <= 0 disables the threshold (typemax(Int32)); fraction must not exceed 1.

Minimap2.map_anchors — Function
map_anchors(index, sequence, opt; qname=nothing) -> (anchors, rep_len)

Query minimizers, their seed hits in index and the anchors sorted by reference position (the stage that minimap2 --print-seeds reports). opt must have been updated for index (its mid_occ set).

Minimap2.map_chains — Function
map_chains(index, sequence, opt; qname=nothing) -> (regions, anchors, rep_len, mini_pos)

Seeds, chaining (with minimap2's re-chaining rules) and the regions generated from the chains, before primary/secondary selection: the stage that minimap2 --print-chains reports.

source
Minimap2.map_query — Function
map_query(index, sequence, opt; qname=nothing) -> (regions, rep_len)

Map one query (minimap2 mm_map): chaining, primary/secondary selection, divergence estimate, base-level alignment with F_CIGAR and mapping quality. qname seeds the hash that breaks ties between equal chains, as on minimap2's command line; without it the seed is that of --no-hash-name.
